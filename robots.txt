# Pre-launch. The site is public on GitHub Pages but is not finished.
#
# Crawling is deliberately ALLOWED below, because the real protection is
# the <meta name="robots" content="noindex"> in every page's <head>.
# A crawler has to fetch a page to read that directive. Blocking with
# "Disallow: /" would hide the noindex, and the URLs could still be
# indexed from external links, showing up as bare results with no snippet
# and no way to suppress them.
#
# AT LAUNCH: delete the noindex meta line from all 10 pages, then remove
# the AI-crawler blocks below if you want the content used for training.
